Key Contrast with Arithmetic
On SVAMP and ASDiv, the 3B solo scored 30.7% and 28.7% — far below baseline — due to answer extraction failures (20–30% empty responses). On CSQA, it scores 75.0% with zero empty answers. The collapse was format-specific: numeric answers require #### N format which the untuned 3B doesn't produce. MCQ answers are just letters — no format discipline needed.

Three-Tier Bias Finding
There is a clean three-tier structure: 1.5B baseline at 24.8% E-bias → 3B solo at 18.8% (partially reduced by scale) → guided pipeline at 14.0% (further reduced by fine-tuned planning). Larger models are less positionally biased. Fine-tuned guidance suppresses bias beyond what scale alone achieves. Both levers work, but they work at different layers.

The 3B model's mild D-preference (+3.1 pts over expected, 23.1%) is not a collapse. Compare it to the 1.5B baseline's E-preference at 24.8% — that's already milder. Compare both to PIQA's A-option collapse at 93.4%. CSQA 3B solo is essentially unbiased at the practical level.

Accuracy by Option — An Interesting Pattern
When the 3B model picks option A or B, accuracy is 81.7%–81.8%. When it picks option E, accuracy drops to 69.2%. This suggests residual uncertainty is more concentrated in the E option — the model picks E when less certain. The mild D-preference (71.2% accuracy) is slightly safer than E. This is characteristic of MCQ behaviour in models that have reduced but not eliminated positional priors.

When the 3B model agrees unanimously (5/5), it is right 87.5% of the time. That is a strong signal — the model knows what it knows. False confidence (confident and wrong): 138 cases = 15.3%. That is higher in absolute terms than desirable, but the ECE is low because the model is also frequently correct when unanimous.

Why 3B ECE Beats Guided on CSQA
The 3B model at full parameter scale on a pure MCQ task produces more decisive, more uniform votes. 593/900 questions (65.9%) reach unanimous agreement vs fewer for the 1.5B solver. When a 3B model is confident, it tends to be right. The guided pipeline's ECE (0.141) is still much better than baseline (0.176), but the 3B solo at 15.0B param-passes achieves the tightest calibration. This is the expected behaviour — scale improves calibration on MCQ when answer format is trivial.
04 Implications for the Paper's Claims

These results do not weaken the paper. They sharpen it — with more precision about when and why the guided pipeline is the right choice.

Claim: Fine-tuning quality, not size, drives gains
✓ Supported. 3B solo achieves 75.0% purely from scale. Guided achieves 75.8% with 30% less compute. The fine-tuned guide adds +0.8 pts while costing 4.5B fewer param-passes. The marginal value of fine-tuning is efficiency, not just accuracy — on MCQ where size already helps.
Claim: Guided pipeline beats all compute alternatives
✓ Supported with nuance. Guided (75.8%) beats baseline (70.7%) and 3B solo (75.0%) at 10.5B vs 15.0B. The pipeline is the Pareto-optimal choice: best accuracy, lower compute than solo. On MCQ tasks the margin is small (−0.8 pts) but the compute saving is real.
Claim: 3B solo "collapses" below baseline
⚠ Needs precision. True on arithmetic (SVAMP: 30.7%, ASDiv: 28.7% — both below baseline). False on MCQ (CSQA: 75.0% — above baseline by +4.3 pts). Reframe as: "3B solo collapses on numeric open-answer tasks due to output format failure; on MCQ it is competitive but less compute-efficient than the guided pipeline."
Claim: Fine-tuned guidance suppresses position bias
✓ Strongly supported with new layer. Three-tier structure confirmed: 1.5B baseline (24.8% E-bias) → 3B solo (18.8%) → guided pipeline (14.0%). Scale reduces bias partially. Fine-tuned planning reduces it further. Both mechanisms are real and separable.
New finding: Format vs reasoning failure mode
★ New contribution. Numeric task collapse = output format discipline missing (20–30% empty responses). MCQ task success = format trivial (just a letter). This format-specific collapse is a mechanistic finding that explains the 3B solo data across all three datasets and belongs in the paper.
The Sentence That Belongs in the Paper
"On multiple-choice tasks where answer format is trivial (a single letter), the 3B model achieves competitive accuracy (75.0\% vs guided 75.8\%) but requires 43\% more compute. On numeric open-answer tasks, the untuned 3B produces 20–30\% empty responses due to output format failure, scoring below the 1.5B baseline. The guided pipeline is the only configuration that generalises across both task types at intermediate compute cost."
The 3B solo is not universally weak — it is format-constrained. That distinction is the finding.
