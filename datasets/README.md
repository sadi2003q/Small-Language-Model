# Datasets Used

Datasets are not uploaded due to license restrictions. Links to official sources are provided.

---

## 1. SVAMP

* Source: Hugging Face (ChilleD)
* Link: https://huggingface.co/datasets/ChilleD/SVAMP
* Description: Arithmetic word problem dataset.

---

## 2. ASDiv

* Source: Hugging Face (EleutherAI)
* Link: https://huggingface.co/datasets/EleutherAI/asdiv
* Description: Arithmetic reasoning problems.

---

## 3. AI2 ARC

* Source: Hugging Face (AllenAI)
* Link: https://huggingface.co/datasets/allenai/ai2_arc
* Description: Science multiple-choice questions.

---

## 4. CommonsenseQA

* Source: Hugging Face (TAU)
* Link: https://huggingface.co/datasets/tau/commonsense_qa
* Description: Commonsense reasoning dataset.

## 5. RACE

* Link: https://huggingface.co/datasets/ehovy/race
* Description: Reading comprehension dataset.
